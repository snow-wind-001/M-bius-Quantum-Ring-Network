# Temporal MQR-v5/v6：未来行为收益驱动的在线写入

> 日期：2026-08-25。v5 权威结果为
> `analysis/results/temporal_mqr_utility_digits.json`，独立校验器为
> `analysis/temporal_mqr_utility_verify.py`。本阶段证明并验证的是一个研究级
> 延迟信用分配原型，不是 2B 生产运行时、一般动物学习或相对 GRU/LoRA 的优势。

## 0. v6 反转与跨任务复验

v6 保留 v5 的未来收益目标，只新增严格过去的上下文波动迹和两个
硬路由收益专家。路由无任务 ID，每个专家仍只学习“本次保存是否改善
未来行为”，不学事件身份。单样本硬路由使未选专家原始梯度为零；由于
OGD 历史基也保持专家块支撑，投影和全局范数裁剪后仍精确零更新。

5 个新 seed 的 A→B→A 正式流已加入 GRU、fast-weight、LoRA、OGD-LoRA
和 equal-byte replay。在 288–320 可塑参数与 4096 B 在线张量状态上限下，
双专家 MQR+OGD 相对 LoRA 将 A-after-B 下降减少 `36.75 pp`，配对
bootstrap 95% CI 为 `[34.00,39.50] pp`；最终平衡准确率高
`11.63 pp`。但其全过程平均阶段准确率低 `8.58 pp`，且延迟为
`36.31 ms` 对 LoRA 的 `0.48 ms`。更重要的是，总 sidecar 参数尚未对齐
（1354 对 300），FLOP 也未匹配。因此 v6 已将结论推进到“有独立的稳定性
机制”，仍没有证明“独立总体竞争力”。完整协议与结果见
[`mqr_reversal_go_v2_report.md`](mqr_reversal_go_v2_report.md)。

## 1. 核心结论

v5 已把学习目标从“这是什么事件”改为“保存它是否降低未来任务损失”。当前
观察总是进入快环；低秩门只依据决策前可获得的新颖性、不确定性、过去预测误差、
慢环饱和度和上下文变化，决定是否立即写慢环。每个候选同时保存一对仅在该次
写入上不同的影子轨迹。未来标签到达时，以

\[
A_{t\to\tau}=\ell_\tau(h_\tau^{\mathrm{no\ write}})
-\ell_\tau(h_\tau^{\mathrm{write}})-c_{mem}
\]

监督门的期望收益回归，而不提供 cue/non-cue 标签。漏写且收益为正的候选可在
下一状态转移晋升到慢环；已经发生的有害误写不能倒退删除，运行时会明确报告。

这没有改变 MQR 的底层数学：Cayley 酉参数化、`H=|U|²` 双随机传播、快慢环
阻尼和参数空间 OGD 均保留。变化发生在**外部受迫项的决策策略**，不是环的
齐次传播算子。因此它与原初“稳定环形记忆 + 正交在线巩固”方向一致，而且比
事件身份分类更接近行为信用分配。

## 2. 系统结构与因果事务

对快环与慢环分别写成

\[
h^f_t=\sigma(q_fh^f_{t-1}H_f^\top+J_f(x_t)),
\]

\[
h^s_t=\sigma(q_sh^s_{t-1}H_s^\top+a_tJ_s(x_t)+r_t),
\qquad a_t=\mathbf1[\hat A_\phi(z_t)>0].
\]

其中 `z_t` 只依赖 `x_≤t`、过去状态与 `y_<t`；`r_t` 是此前已获正收益反馈的
候选晋升项。一次事务严格执行：

1. 从过去信息构造 `z_t`，旧门参数产生动作；
2. 推进真实状态，并从同一旧状态建立 write/no-write 影子分支；
3. 后续观察以完全相同的实际动作推进两个分支；
4. 未来标签到达后才计算 `A`，使用缓存 `z_t` 重算当前门梯度；
5. 门与读出分别做完整向量 OGD 和独立范数裁剪，再提交未来版本。

影子差值是在“未来动作固定为实际动作”的条件下，对单次写入干预的有限时域
边际效应。它不是允许未来策略随反事实状态重新决策的总因果效应，也不是无偏的
无限时域回报估计。

## 3. 数学保证及没有改变的部分

若 `σ` 为 1-Lipschitz、`H` 双随机，同一输入、门和晋升项下两个状态满足

\[
\|h_t-h'_t\|_\infty\le q\|h_{t-1}-h'_{t-1}\|_\infty.
\]

`a_tJ(x_t)` 和 `r_t` 在作差时消失，所以外部晋升不会改变收缩常数。Cayley
生成的 `U` 仍严格保酉，`H` 仍双随机；若激活为 `tanh`，任意有界或暂时较大
晋升也不会使状态发散。无状态激活时则需晋升有界，代码为累积晋升设置范数上限。

门用裁剪后的标准化收益做均方回归：

\[
\min_\phi\mathbb E[(v_\phi(z)-\widetilde A)^2].
\]

在平方可积且函数类充分时，点态风险最优解为
`v*(z)=E[Ã|z]`；没有共享容量耦合时，`v*(z)>0` 是二动作期望损失意义下的
Bayes 写入规则。目标裁剪会把它变为裁剪收益的条件均值，这是稳定性与无偏性的
明确交换。

参数 OGD 的保证与 v4 相同：对白化梯度 `w=D^(1/2)g` 和历史正交基 `Q`，

\[
\Delta\phi=-cD^{1/2}(I-Q^\top Q)w,
\quad g^\top\Delta\phi=-c\|(I-Q^\top Q)w\|^2\le0.
\]

它只保证当前损失一阶不增、与已保存梯度一阶正交；不保证有限步全局下降或旧
行为完全不忘。环传播的“酉/双随机约束”和参数更新的“梯度正交”是两个不同
层次，不能合并宣传为整个系统处处正交。

还有一个不可绕过的下界：若决策特征满足
`P(z|未来有用)=P(z|未来无用)`，则任何当前因果门对二值有用性的预测都不能
优于先验常数分类器；若更强地有完整写入收益 `A` 与 `z` 独立，期望收益动作
也不能优于常数策略。仅有二值独立时，收益幅度仍可能携带额外决策信息，二者
不能混为一个命题。候选缓存允许反馈后补写并为未来相似事件学习，但不能改善第一次、
不可预测且已经结束的查询。该限制不是网络宽度或优化器可以消除的。

## 4. 无 marker Digits 原理实验

每个 episode 先重复两次随机背景 digit，再给出 5 个随机顺序候选：4 个相同
背景和 1 个不同类别的目标，最后用全零帧查询目标类别。目标位置均匀随机，没有
marker、query bit 或即时事件标签。目标可由相对历史的新颖性因果识别；这使
任务可学，但也意味着它不是“任意未来相关性”测试。

所有条件共享一次 500 样本 predict-before-update 读出校准，随后冻结读出和
reservoir。门训练 200 个 episode，held-out 评估 100 个 episode，3 seeds；
所有 5,521 个参数逐 seed 初始化匹配，在线门只有 49 参数。OGD 条件固定在
episode 0/80/160 的第一个候选采样一个历史梯度，最终 rank 为 3；本阶段没有
系统扫描采样周期，因此不能把该设置当作普适最优值。

| 策略 | Held-out 准确率 | 目标写入 | 干扰误写 |
|---|---:|---:|---:|
| 延迟收益门 + OGD | **72.00±6.24%** | 100% | 0% |
| 延迟收益学习门 | 57.67±27.23% | 100% | 9.83±17.03% |
| 同门但不更新 | 10.33±3.79% | 0% | 0% |
| 因果 novelty 阈值 | 72.00±6.24% | 100% | 0% |
| 知道目标位置的 oracle | 72.00±6.24% | 100% | 0% |
| 全写慢环 | 8.67±3.79% | 100% | 100% |
| 同期望稀疏度随机写 | 17.00±3.00% | 21.67% | 17.17% |

OGD 学习门相对不更新门配对提升 `+61.67±5.03 pp`，相对全写和随机稀疏写
分别提升 `+63.33±9.50` 和 `+55.00±7.55 pp`。目标与干扰的实际平均写入
收益分别为 `+1.097±0.080` 和 `-0.463±0.120` 交叉熵单位；OGD 门预测
分别为 `+1.080±0.078` 和 `-0.413±0.052`。语义目标 AUPRC 为 100%，但逐票据
“收益是否大于零”的 AUPRC 只有 `75.19±2.89%`：部分边际效应受候选位置和
既有写入影响，说明精确效用排序仍未解决。

OGD 版本只保存 3 个 49 维方向（588 bytes），训练流平均准确率从
`46.67±8.13%` 提升到 `64.17±5.92%`，配对增量为 `+17.50±3.04 pp`。
held-out 平均提升 `+14.33±24.83 pp`，却完全来自 seed 7 的普通门误写塌缩；
另两个 seed 差为零。因此可以说本协议中 OGD 稳定了在线适应并避免了一次
塌缩，不能说已稳定证明泛化优势或跨任务少遗忘。

## 5. 工程边界与下一阶段

当前每个票据保存两个 48 维状态、一个 48 维 payload 和 5 个特征，FP32 裸
张量约 596 bytes，且每帧要推进所有未决分支。它适合小模型精确研究，不适合
逐 token 复制 2B/KV-cache。此次 episode 评估还关闭了反馈后晋升并在 episode
间重置，因而任务增益来自学会**提前写入**；延期晋升只由严格单元测试验证。

下一阶段应依次完成：

1. 用随机投影的状态差/JVP 近似影子分支，并与精确 `A` 校准偏差；
2. 设计相关性会反转的流，验证门从 novelty 转向真正的历史回报规律；
3. 用 two-task/reversal 协议检验 OGD 是否降低旧策略遗忘；
4. 匹配训练参数、状态/replay bytes、反馈时机和计算量，与 GRU、fast-weight、
   LoRA、OGD-LoRA 和 equal-byte replay 比较；
5. 再将冻结 MiniCPM 隐状态作为 `x_t`，只在句段或对局事件级签发候选，而非
   每 token 建立影子分支。

只有在这些等预算基线中仍保持较小 oracle gap、更低遗忘和可接受延迟，才能把
v5 从“符合初衷且有正结果的机制原型”提升为“具有独立竞争力的 MQR 算法”。
当前 v6 已完成上述第 2–4 项的第一轮可识别反转验证，但“等预算”仍只到
可塑参数和张量状态上限，尚缺总参数/FLOP 匹配与学习路由。第 1 项影子近似也尚未
完成，它是将 75 倍延迟差缩小到实用范围的必要条件。
