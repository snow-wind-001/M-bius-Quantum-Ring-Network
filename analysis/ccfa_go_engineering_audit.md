# CCFA 工程诊断：为什么围棋仍然较弱

2026-09-11。审查基线为 907a943。本次使用 CCFA 的机制—证据审查方法，以 ccf-idea-optimizer 的问题/机制框架定位根源，并按 ccf-experiment-designer 的证据要求核查对照。采用标准模式和通用 AI/ML 研究视角；不进行论文评分或投稿判断，不修改算法实现。

**判断：存在严重的系统设计缺口和一个已测到的读出功能退化。现有证据不足以否定正交环本身。** 当前主模型缺少以真实胜负改善为目标的学习路径；其位置查询分支几乎没有影响实际落子，在线适应主要依靠对冻结空间特征的全局通道调制。应先修复这些问题，再评价增加环数或更复杂约束是否有价值。

## 1. 证据范围与新发现

原实验记录为五个种子 401/409/419/431/443。本次读取 transport1 和 transport1_guard 共十个最终检查点，在原留出轨迹和原评估棋谱上做冻结参数干预：

- 完整模型。
- 每个观察都清空之前的环状态，但保留当前观察的注入与所有已学参数。
- 仅使用该模型原本冻结的空间骨干，保持相同合法性先验尺度。
- 关闭位置查询校正，保留环状态、通道调制和停着分支。
- 去掉学习得到的合法性先验，仍保留环境的精确合法落子过滤。

完整模型的 A/B 留出 NLL 与原 JSON 一致；空间骨干的 NLL 与原训练前指标一致；80 局评估中全部 1235 次实际学生决策逐次复现。检查点文件哈希保持不变，训练更新次数为零。干预是在同一局面上的局部因果检查，不是重新训练的对照，也不将其替代正式棋力成绩。

## 2. 第一根源：训练目标没有直接指向赢棋

当前主流程的训练损失可以概括为：

\[
\mathcal L =
\mathcal L_{\mathrm{placement}}
+\mathcal L_{\mathrm{legality}}
+\mathcal L_{\mathrm{pass}}
+0.2\mathcal L_{\mathrm{illegal\ mass}},
\qquad \lambda_{\mathrm{value}}=0.
\]

教师使用捕获、气数、连接、中心偏好和自紧气惩罚做一步评分。学生没有获得“这个动作最终导致了输棋”的更新信号。底层 agent 虽有 value、AWR、PPO 接口，但当前驱动没有提供这些目标。检查点在本次全部被检查局面上的价值输出均为零。

代码证据：

- [主模型配置与冻结策略](../experiments/go_memory_research.py#L70)，尤其 103–105、122–127 行。
- [学生先预测后反馈](../mqr/go_online.py#L239)：反馈调用不传 value_target。
- [实际动作选择](../mqr/go_online.py#L151)：对精确合法动作取 argmax。
- [启发式教师](../mqr/go.py#L293)。

降低教师动作 NLL 能改善概率估计，却没有保证最高分动作改变，更没有保证改变后的动作带来更高胜率。教师存在并列动作、启发式偏差，测试局面也由学生的行为决定，因此 NLL、模仿准确率、赢棋能力必须分别测量。

AlphaZero 将搜索得到的策略分布与真实终局结果分别作为策略和价值目标，并使用策略/价值共同指导搜索。这一因果链正是当前主实验缺少的环节；它不意味着小模型必须复制 AlphaZero 的规模或预算。[原始论文](https://arxiv.org/html/1712.01815)

还有一个必须先处理的后续风险：现有 generate_go_agent_trajectories 在 recorded_moves 达到上限后直接调用 board.winner()，未要求棋局真正结束。这些 value_target 是截断局面的当前面积评分符号。当前 value=0，因此它不是本轮成绩下降的直接原因；但以后不能只把 value 权重打开就称为真实终局价值学习。

## 3. 第二根源：位置查询几乎退化为公共偏置

GoResearchCore 的三个环共有 48 个标量槽。每个棋盘位置用空间特征生成查询，查询与学习得到的固定槽地址比较，再对环内容加权求和：

\[
\alpha_{pj}=\mathrm{softmax}_j(q_p^\top k_j/\sqrt d),\qquad
r_p=\sum_{j=1}^{48}\alpha_{pj}v_j,\qquad
c_p=w^\top r_p.
\]

目前槽 key 是独立学习的地址参数，未由当前槽内容生成。原始槽值是相邻四个标量组成的向量；没有显式的棋盘位置—环槽绑定。这个结构并非必然不可学习，但要求优化过程同时学会写入编码、槽地址和有区分力的查询。

新诊断显示，transport1 在 B 留出集上的五种子结果为：

| 种子 | 查询注意力归一化熵 | 查询带来的落点中心化 logit RMS | 通道调制带来的落点中心化 logit RMS |
|---|---:|---:|---:|
| 401 | 0.99475 | 0.0000362 | 0.8357 |
| 409 | 0.99799 | 0.0000169 | 1.8654 |
| 419 | 0.99526 | 0.0000275 | 0.2358 |
| 431 | 0.99540 | 0.0000324 | 1.9423 |
| 443 | 0.99592 | 0.0000173 | 1.6271 |

熵 1 表示在 48 个槽上均匀分配。单看熵不足以判定失败，因此同时测量了真正影响相对选点的中心化 logit，并直接移除查询校正：所有被检查决策均不改变。guard 检查点也出现同样现象。

### 为什么它会不容易学起来

在均匀注意力极限下：

\[
r_p=\bar v\quad\forall p,\qquad c_p=c.
\]

而 softmax 满足：

\[
\mathrm{softmax}(z+c\mathbf1)=\mathrm{softmax}(z).
\]

因此，所有棋盘位置得到相同的校正，无法改善落点的相对排序。令交叉熵对各落点 logit 的导数为 g_p，则 \(\sum_p g_p=0\)，从而：

\[
\frac{\partial\mathcal L_{\mathrm{placement}}}{\partial w}
=\sum_p g_p r_p
=\bar v\sum_p g_p=0.
\]

当注意力只是接近均匀时，这个梯度由很小的位置差异决定。此外，当前 point_correction 零初始化，使查询 key、query 和 value 路径在初始化处通过该校正头得到的梯度为零；空间通道调制则可以较快利用已经存在的局部特征。两条路径之间出现明显的优化不平衡。

这一推导针对落点交叉熵与公共偏置极限。合法性 BCE、非均匀注意力和其他读出路径仍可提供梯度，因此不能把它扩大为“整个模型永远没有梯度”。实测结论是：当前 Go 检查点的按位置查询作用极弱。

[对应实现与零初始化](../mqr/go_memory.py#L197)。

## 4. 第三根源：实际发挥作用的架构仍然很受限

当前主实验实际运行的是：

~~~text
当前棋盘 → 两层 3×3、12 通道的冻结空间骨干 → 局部特征
当前棋盘 → 共享 8 维注入 → 三个并行环 → 16 维读出 → 通道增益
局部特征 × 通道增益 → 落点分数
局部特征 → 位置查询 → 环内容校正（当前实际影响极小）
策略分数 → 环境合法过滤 → 贪心落子
教师动作 → 有限窗口更新 → OGD / 可选 KL
~~~

两层 3×3 卷积的最大感受野为 5×5；靠近边角的有效棋盘覆盖更小。在当前 5×5 棋盘上中心位置可覆盖全盘，不能说所有位置都只看局部。但这种浅层、冻结的表征不容易针对新的棋块连接、气数、局部死活错误重学特征。新增在线容量主要用于调制既有特征。

从参数配置看，5218 个可训练参数中，2592 个用于输入条件化角度控制器，空间骨干的在线可训练参数为 0。这是明显的容量分配取舍：大约一半可训练参数负责决定“怎样转动状态”，但识别棋盘结构的基础特征被冻结了。不能据此证明条件旋转无用；应以同预算的空间更新/简化控制器对照判定。

三个环也并不是三层层级推理。固定输入时：

\[
h_{t+1}^{(r)}
=\rho_rR_r(x_t)h_t^{(r)}
+\beta_rU_r\tanh(Vx_t),
\]

且对不同环有：

\[
\frac{\partial h_{t+1}^{(r)}}{\partial h_t^{(s)}}=0
\quad(r\ne s).
\]

它们通过共享输入和联合读出联系，状态演化本身没有环间消息传递。OGD 在参数更新上施加联合约束，不会自动产生层级棋形推理。若目标是类似深层残差网络的逐层能力提升，需要明确额外计算过程，而不是仅增加并行环数量。

共享 8 维注入也不等于历史容量永远只有 8 维：旋转乘积可使不同时间的输入进入不同方向，输入条件化转移还能形成额外编码。这是结构瓶颈假设，不是容量不可能定理。

## 5. 第四根源：历史任务和围棋主任务不在同一条收益链上

专门的历史任务要求预测黑棋第一着的中心对称点。它证明了某些历史差异可以经过训练被读出，没有证明这种信息对围棋胜负有帮助。

在当前启发式教师下，一旦给定棋盘、执棋方、停着状态和精确合法动作集合，教师动作就是确定的。其余历史不再为这个即时标签增加信息。主对局又在模型之后应用精确合法过滤，因此测试环境已经承担了重要的历史规则判断。

本次移除 position_history、保留相同当前棋盘的诊断中：

- transport1：1287 个观察局面，只有 3 个改变合法集合和教师动作。
- transport1_guard：1534 个观察局面，只有 4 个改变合法集合和教师动作。

这是针对现有轨迹的事后诊断，不是可达历史配对训练数据，也不意味着真实围棋不需要历史。它说明当前主对局没有充分激发我们要研究的长历史机制。

另一个错位在信用长度：状态可以跨窗口延续，但学生更新仍最多在当前 8 个观察内反传；完整历史伴随主要用于行为锚点和独立历史实验。状态“还存在”与早期写入“还能从当前错误得到训练”是不同概念。

三个环的携带率分别为 0、0.85、0.97。对应历史振幅半衰期为 0、4.27、22.76 个观察；最慢环在 64 步后对初始扰动的直接携带因子约为 0.142。正交消除了旋转本身的额外范数损失，没有消除泄漏或截断造成的信息/信用限制。

## 6. 第五根源：保护了行为，还没有保护“值得保留的能力”

OGD 满足保留方向上的局部约束，KL 检查限制有限步策略变化；二者没有自动判断旧行为是否正确。

本次 40 个不重复 A 阶段锚点中，参考策略的原始 argmax 只有 19 个等于教师动作，平均教师动作概率约为 0.450。两个后端共用这些参考锚点，不能当成 80 个独立样本。这不是最优棋力准确率，只能说明参考行为连教师模仿都不可靠。

正式结果中，加入 KL 后最大锚点 KL 从约 0.126 压到 0.01 容差以内，胜场却从 8/40 变为 5/40。样本不足以证明 KL 必然损害棋力，但足以反驳“漂移更小必然下得更好”的解释。

同时，A/B 阶段仍是同一个教师，只改变局面分布。多数方法在 B 训练后，A 留出 NLL 平均也改善；当前主要困难并没有被证明是严重灾难性遗忘。因此不能默认把更大的保护秩或更严格的 KL 当成主要棋力优化方向。

还有已知的状态一致性边界：在线更新后保留的活跃状态由旧参数产生，而锚点是在当前参数下从零重放。输入采用固定黑白坐标，不能消除学习到的编码和旋转随参数变化的问题。当前漂移保证针对锚点重放；活跃混合参数版本状态需要单独测量。

## 7. 实际输棋已经出现基础战术症状

在原 40 局 transport1 评估中，去掉随机开局后，逐次复现了 556 个学生决策，其中 515 次为落子：

- 88 次落子不提子且使新棋块只剩一口气；在相同决策局面，教师动作出现这一现象的次数为 18。
- 83 次新落下的棋子在对手紧接着的实际回复中被提掉，即 83/515，约 16.1%。
- 53 个局面存在立即提子的合法动作，其中 36 次学生没有提子。

自紧气、弃子或不立即提子不一定是错误，不能将上述次数直接解释为最优策略损失。但这些实际症状，加上没有价值/搜索判断，足以要求先检查基础战术表征和动作排序，而不是优先归咎于记忆长度不足。

以下为 transport1 的 B 留出集五种子均值，所有干预在原局面上评估：

| 固定参数干预 | 教师动作 NLL，低为好 | 合法 argmax 与教师一致率 |
|---|---:|---:|
| 完整模型 | 2.15742 | 34.03% |
| 每次清空历史 | 2.25787 | 35.59% |
| 原冻结空间骨干 | 2.46612 | 36.39% |
| 关闭位置查询 | 2.15742 | 34.03% |

记忆确实改善了概率预测，不能说完全无效；但当前落子选择并没有随之改善。固定观察的动作一致率不能推导干预后的胜率，因为改变动作后会访问不同局面。

## 8. 保留正交、环网络、在线更新的修正路线

### 优先级 0：先让训练与决策目标一致

1. 将真正的终局结果回传到价值学习，明确当前执棋方符号、终局与手数截断；不把当前面积符号当最终胜负。
2. 保留在线预测先于反馈的协议，使用短期样本存储等待真实延迟结果；区分记录回报所需的存储与反传信用长度。
3. 同时测量教师模仿、战术错误、真实胜负。使用可信教师或明确预算的搜索策略分布作为动作训练目标，避免只拟合任意并列动作。
4. 在相同网络上比较无搜索和固定预算搜索，分别报告神经网络能力与搜索系统能力。

KataGo 的原始实验支持用棋盘归属、分差等辅助目标提供比单个胜负标签更细的反馈，并通过全局信息帮助局部推断。这是可以借鉴的机制，不是当前项目已经得到的收益。[原始论文](https://arxiv.org/html/1902.10565)

### 优先级 1：修复有效读出与空间适应

1. 保留正交状态传播，让棋盘位置与写入/查询坐标建立明确联系；比较多通道位置状态与当前无结构标量槽。
2. 打破查询校正的公共偏置退化，例如训练侧的历史差异 margin 目标、受控的小幅非零校正初始化。不能仅强制注意力变尖锐就声称修复。
3. 允许部分空间特征或小型空间适配器在线更新，并把相关参数纳入同一个行为约束系统。正交核心不要求所有读出和局部特征提取层都必须正交。
4. 简化角度控制器，与增加空间特征能力做等总参数、等内存/耗时对照。不能只扩大整个模型后将收益归因于环结构。
5. 验收必须包含：查询校正对正确动作 margin 的贡献、移除查询的任务退化，以及新种子上的复现。

### 优先级 2：让约束与在线任务有明确关系

1. 区分“应维持的可靠行为”和“应该被新反馈纠正的旧错误”；以训练侧证据定义保护对象。
2. 对可靠分数采用有限退化约束，允许朝更好方向更新，而不是对整个旧策略施加一概不变的要求。
3. 用真实可达超级劫任务检验历史规则，用持续对手分布变化检验在线适应；标准围棋胜负与这些机制诊断分别报告。
4. 只有在更长信用确实改善这些任务时，才扩大反传跨度，并计费锚点、状态、梯度基底和实时延迟。

### 优先级 3：再探索真正的环间/跨层计算

若前述瓶颈解决后，仍缺少全局组合能力，可以探索含环间 Givens 混合的整体正交转移，或者受保护子空间中的残差计算。应先给出实际 Jacobian：输入条件化可以保留原有状态伴随公式；若旋转依赖隐状态，就会出现额外导数项，不能沿用旧证明。

现有正交—伴随—OGD 链条可以作为这些结构的约束基础。当前显式伴随与完整自动微分等价，本身不会制造额外的策略改进方向。

## 9. 最小鉴别实验，而不是继续堆配置

| 要决定的问题 | 必要对照 | 主要判据 |
|---|---|---|
| 基础空间特征是否限制棋力 | 当前冻结骨干 vs 同预算空间适配；均保留环与相同 OGD | 战术错误、动作质量、终局胜率；同教师、相同训练规模 |
| 位置查询是否被激活 | 当前读出 vs 修正读出；保持状态预算和信用一致 | 历史 margin、移除查询的实际影响、独立确认种子 |
| 缺的是回报还是记忆 | 仅模仿 vs 模仿加真实终局价值；结构与搜索预算相同 | 价值校准、终局胜率、错误类型 |
| 正交机制是否有独立作用 | 学习正交、固定正交/移位、等预算递归对照 | 同等资源下的历史收益—漂移—适应速度取舍 |
| 保护是否针对有价值能力 | 普通 OGD/KL vs 可靠行为保护；同范数控制 | 可靠旧任务退化、新任务收益、胜率 |
