# 围棋读出、空间适应与真实终局反馈：实施方案

起点为 907a943 与 CCFA 工程诊断。保留正交多环、在线预测先于反馈、联合 OGD 和固定参考 KL。旧类和默认行为保持兼容。

## 实现边界

1. 新增有符号位置查询：几何查询、非凸加权读取、落点中心化校正和小幅非零初始化，解决均匀注意力/公共偏置退化。环状态转移保持不变。
2. 允许空间骨干参与同一个受约束在线更新；只在新增实验配置启用。
3. 对已提交的实际观察保存有界回合记录。只有棋局真正终止才赋予执棋方视角的胜负标签；采用当前参数重新预测的明确回放更新。手数截断不生成终局标签。
4. 增加相同回放次数的纯模仿对照，区分多做更新与价值监督的作用。
5. 增加只保护当前参考策略正确模仿教师的锚点选择；允许没有可靠锚点时显式返回空基底，不伪造可靠性。
6. 增加固定模拟预算的策略/价值树搜索，独立报告贪心和搜索结果；搜索不调用教师，不更改线上状态或参数。

## 预先确定的确认实验

开发种子 1801；正式种子 503、509、521、523、541。正式开始前固定完整实现和配置。

主对照：旧模型、修正查询、查询加空间更新、再加纯模仿回放、再加真实终局价值、再加可靠锚点。除单项干预及明确的参数增量，各组共享种子、预训练骨干、教师、阶段开局及更新规则。所有方法均保留正交环和 OGD/KL 协议。

默认 5×5，16×3 环状态，12 空间通道，16 维核心读出；预训练 24 局前缀、24 轮；A/B 各 8 局；窗口/信用 8，锚点最多 8、秩最多 8。确认评估每种子 16 局，8 个合法开局换色。搜索在相同最终检查点上另行运行，预算 16 次模拟，最多 8 层。既有结果不覆盖。

验证内容：新读出的参数梯度及伴随等价性、非零任务 margin、空间参数更新与保护投影、终局/截断区别、执棋方标签符号、回放时序、搜索分支状态隔离、完整恢复。再执行核心回归和数学检查。

报告内容：真实终局胜率、分差、即时战术风险、教师 NLL 与动作一致率、价值误差、查询移除效应、锚点实际漂移、数据/回放次数、延迟与内存。区分冻结局面干预、正式对局与开发运行。若未见棋力改善，报告失败及其证据，不更换确认种子。

开发阶段完成全部六种方法的端到端小规模检查，并完成旧模型与新查询的完整预算开发运行；随后在正式运行前补充了非法搜索参数的无副作用拒绝。完整开发队列在这个接口修正处中断，保留其已有数据，不作为正式证据。没有根据开发胜率调整模型超参数或更换确认种子。

正式参数保持以上默认值。搜索仅对 legacy 与 reliable 两个事先指定的端点进行，二者都用 16 次模拟、8 层预算；其余四组仅进行贪心棋力比较。正式六组、五种子全部执行完整训练与 16 局冻结评估。纯模仿回放与价值回放对每条实际终局轨迹使用相同更新规则；轨迹随策略变化，因此总回放样本数和更新数不强称相同。

持久在线张量占用以真实观察窗口中记录的峰值报告，排除临时自动微分图、锚点刷新工作区、搜索树和 Python 对象。逐观察延迟与包含终局回放的阶段总耗时分别报告。实验并行使用独立 CPU 进程，每个 PyTorch 进程一个线程，机器不独占。
