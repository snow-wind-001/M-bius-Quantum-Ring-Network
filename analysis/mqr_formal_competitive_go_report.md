# MQR 10×10/13×13 等资源正式在线学习报告

> 权威结果：`results/unified_temporal_mqr_go_competitive_10x10_formal_10seed.json`
> 与 `results/unified_temporal_mqr_go_competitive_13x13_formal_10seed.json`。
> 联合审计：`results/unified_temporal_mqr_go_competitive_joint_verify.json`。

## 结论

本轮已经满足预注册的工程与实验条件：10 个正式 seeds、每任务 128 次主在线
反馈、10×10 主实验、13×13 同协议复验，以及 identity、GRU、LSTM、fast-weight、
LoRA、OGD-LoRA、replay-LoRA 和隐式 Sinkhorn 对照。原来的状态量比 `5.333`
已降为精确 `1.000`：所有方法均为 3 个时间尺度、每尺度 4 个 float32 标量，
即每流 48 B。

结果支持“该系统能执行 predict-before-update 在线权重学习”，不支持“MQR 有独立
算法优势”。10×10 和 13×13 的 MQR task-A held-out loss 降低分别为
`2.8331`（95% bootstrap CI `[2.7121,2.9531]`）和 `3.0168`
（`[2.9378,3.0929]`）。但两尺度的历史焦点准确率全部为 `0.500`；MQR 与
identity 在核心决定指标上基本精确打平。联合失败关闭结论为
`mqr_effective=false`。

## 正式协议

- seeds：`7,17,29,43,71,89,107,131,149,173`；
- 每 seed：task A 128 次 opening 更新，task B 128 次 ko/fresh 更新；每方法再在
  task B 获得 128 次等预算辅助梯度样本；
- 每任务 64 个 held-out probe；每阶段 8 局无合法性 mask 的完整动态对局；
- 当前棋盘为 lossless 3-plane + 6 causal scalars；ko/fresh 焦点输入逐元素相同；
- 所有方法共享同一冻结基映射、零初始化自适应残差、局部空间支路、四头、损失、
  数据顺序和内容无关 Bernoulli 写探索；正式评估取消路由覆盖；
- OGD 方法实际达到 rank 4；replay 只保存真实 tensor payload，不用伪 padding；
- 每个方法/seed 接收 256 个唯一教师反馈、384 个梯度样本，严格先预测后更新。

## 为什么独特优势仍未出现

1. ko/fresh 流只有两步，在线性读出附近，一次状态变换容易被读出重参数化；
   Cayley 拓扑没有获得多步组合才可能产生的可辨识作用。
2. 48 B 公平门解决了旧资源缺陷，却把所有有状态核心限制为 12 个标量；这足以
   做机制审计，不足以默认承载 100/169 点棋盘的历史规则。
3. learned gate 在正式 probe 上多为关闭，随机训练探索虽打破早期自举死锁，仍未
   学到可泛化的未来写效用；MQR 历史分离接近零。
4. task B 没有造成可测的 task-A 正遗忘，所有方法的遗忘指标都落在 0 下界。
   当前协议因此无法证明 OGD 或环结构“减少遗忘”。
5. 空间支路让 opening 教师一致率明显提高，但动态合法率仍低；模型学到的是有限
   教师轨迹规律，不是围棋规则或一般问题求解能力。

## 后续机制门审计

上述建议的机制资格点已于 2026-08-29 实施，而非继续盲目扩大 Go
实验。schema-v2 正式任务使用 10 seeds、长度 12、三个重复 query、
160 个主训练 episode 和 40 个反转 episode。cyclic MQR 的历史准确率为
`0.5375 [0.5119,0.5631]`，但 identity 为
`0.5875 [0.5493,0.6257]`；配对 MQR-minus-identity 区间
`[-0.07890,-0.02110]` 全为负。MQR 反转准确率为
`0.3925 [0.3219,0.4631]`，也未过门。

48/192/768 B 容量扫描的三个摊销资源门全部通过，但 MQR-minus-identity
历史准确率仍为 `-0.02875/-0.03250/-0.07125`，最大容量上的
95% 区间为 `[-0.13132,-0.01118]`。单次转移刷新峰值成本比为
`1.1596/1.7122/2.3110`，也全部失败。这些结果排除了“只是状态
容量太小”的解释，并将下一个停止门收紧为：先使自主门显著降低
干扰写率，再要求 identity replacement 明显伤害性能；这两项未通过前，
不再扩大 Go 或 LLM 策略训练。完整结果见
`analysis/mqr_mechanism_and_capacity_report.md`。

当前应用定位仍是冻结小模型的受控在线个性化、会话记忆和错误修正侧车。工程上
13×13 路径可运行且资源可审计；科学上没有证据将其称为通用能力增强器、围棋
学习器或动物式学习系统。
